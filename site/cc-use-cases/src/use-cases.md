Claude Code と Cowork を使って「こんなこともできる！」という事例をまとめました。
プログラミング経験がなくても大丈夫。**Claude デスクトップアプリ** の **「コード」/「Cowork」** タブから、手順どおりに進めれば、誰でも試せます。

## 事例 1: ホームページ作成

### 概要

Claude Code を使えば、自分だけのWebサイト（ホームページ）を数分で作れます。
HTML・CSS・JavaScript といったプログラミングの知識は不要。作りたいイメージを日本語で伝えるだけで、プロ品質のサイトが完成します。

> 👤 **こんな人におすすめ**: ポートフォリオを公開したい方、個人ブログ・小規模店舗の紹介ページが欲しい方、サークル・教室・趣味の活動報告ページを作りたい方

> 🎯 **この事例に向くツール: 「コード」タブ**
> プレビューを見ながら何度も微修正していく **対話型の作業** なので、Claude デスクトップアプリの **「コード」** タブが向いています。
> （Cowork タブでも作れますが、途中で「もう少しこうしたい」と方向転換しづらいので注意）

---

### 必要な準備

- **Claude デスクトップアプリ** がインストール済みでログイン済みであること
- **ブラウザ**（Safari, Chrome など。作ったサイトの確認用）
- （任意）**GitHub アカウント** — 作ったサイトをインターネットに公開したい場合

---

### 手順

#### Step 1: 作業フォルダを作る

サイトを作るための **専用フォルダ** を用意します。

- デスクトップなどお好きな場所に **新規フォルダ** を作成してください（例: `my-site`）
  - 右クリック → 「新規フォルダ」(Mac) / 「新規作成」→「フォルダー」(Windows)
- このフォルダの中で Claude Code が作業します

#### Step 2: 「コード」タブを開く

- Claude デスクトップアプリを起動し、画面左上の **「コード」** ボタンをクリック
- 作業フォルダを聞かれたら Step 1 で作ったフォルダを選択
- 入力欄が表示されたら準備完了です

#### Step 3: CLAUDE.md を作る（デザインの指示書）

> 💡 **CLAUDE.md ってなに?**
> 作業フォルダに置いておくと **Claude が自動で読んでくれる「お決まりの指示書」** です。「いつもこのスタイルで作って」「この色を使って」など、毎回伝える必要がなくなります。

Claude Code に「こんなデザインにしてね」という指示書を渡すと、仕上がりが格段に良くなります。
以下のプロンプトをコピペして入力してください。

```
以下の内容で CLAUDE.md ファイルを作成してください。

# デザインガイドライン
- HTMLファイル1つ（index.html）で完結させる
- ダークテーマ（背景は濃い色）
- メインカラー: #e8643a（暖かみのあるオレンジ）
- アクセントカラー: #3abba8（ティール）
- Google Fonts を使って、おしゃれなフォントにする
- 雰囲気: 落ち着きがありつつも、親しみやすい和モダン
- 背景にグレイン（ざらざら）テクスチャで奥行きを出す
```

> CLAUDE.md というファイルが作られます。これが今後のデザインの基準になります。
> 色や雰囲気は、お好みに合わせて自由に変えてください。

#### Step 4: プランモードで計画を立ててもらう

いきなり作るのではなく、まず「どう作るか」の計画を見てから実行すると安心です。
そのためのモードが **プランモード (Plan mode)** です。

入力欄の近くにある **モードセレクタ** をクリックして、 **「プランモード」** を選びます。
（数字キー **3** でも切り替えられます。入力欄付近に「プランモード」と表示されれば OK）

プランモードのままプロンプトを入力すると、Claude が **実行はせずに計画だけを提示** してくれます。

```
私のビジネス「手作りアクセサリーショップ Hana」の紹介サイトを作ってください。

内容:
- ショップ名とキャッチコピー（ヒーローセクション）
- コンセプト紹介（手作りへのこだわり）
- 作品ギャラリー（ダミー画像でOK）
- 料金・オーダーの流れ
- お問い合わせセクション（SNSリンク）
- フッター

デザイン:
- CLAUDE.md のガイドラインに従う
- スマホでも見やすいレスポンシブデザイン
- スクロールすると要素がふわっと現れるアニメーション
```

> Claude が計画を提示してくれます。内容を確認して、OK なら **モードセレクタを「許可を確認」(数字キー 1) に戻してから** 「この計画で進めてください」と伝えます。

#### Step 5: 作ったサイトを確認する

生成が完了したら、以下を Claude に伝えます。

```
作った index.html をブラウザで開いてください。
```

> ブラウザが開いて、作ったサイトが表示されます。
> Claude デスクトップアプリの「コード」タブでは、チャット画面の中に **プレビュー** が出ることもあります。

#### Step 6: 修正を依頼する

気になる部分があれば、日本語でそのまま伝えるだけで直してくれます。

```
ヒーローセクションの文字をもっと大きくして、背景にぼんやり光るオーブのエフェクトを追加してください。
```

```
ギャラリーのレイアウトを2列から3列に変えて、ホバーしたときに拡大するようにしてください。
```

```
全体のフォントを「Kaisei Opti」に変えてください。
```

> 修正は何度でも無料で頼めます。納得いくまで調整しましょう。

---

### AIっぽくないデザインにするには

AIが作ったサイトは、何も指示しないと「どこかで見たことある」感じになりがちです。
これは、AIが「よくあるパターン」に引っ張られるためです。

#### よくあるAIっぽいデザイン（NG例）

- 紫〜青のグラデーション背景
- Inter, Roboto, Arial などの無難すぎるフォント
- 中央揃えの大きい文字 + 説明文 + ボタン、という定型パターン
- 均等に色を配分した、特徴のない配色

#### 対策1: `/frontend-design` スキルを使う

Claude Code には「AIっぽくならない」ためのスキルが用意されています。
プロンプトの前に `/frontend-design` と入力するだけで、個性的なデザインを提案してくれます。

```
/frontend-design

手作りアクセサリーショップの紹介サイトを作ってください。
ナチュラルで温かみのある雰囲気にしたいです。
```

> スキルがまだ入っていない場合は、Claude に「frontend-design スキルを使えるようにして」と頼むと案内してくれます。

#### 対策2: CLAUDE.md にNGリストを書く

```markdown
# デザインで避けること
- Inter, Roboto, Arial は使わない
- 紫〜青のグラデーション背景は禁止
- 中央揃えのヒーロー + ボタンの定型レイアウトは避ける
- 均等配色にしない（メインカラーを大胆に使う）
```

#### 対策3: デザインの方向性を具体的に伝える

NG: 「モダンでクリーンなデザインにして」（曖昧すぎてAIっぽくなる）

OK:
```
和モダンな雰囲気で、筆文字風のフォント「Kaisei Opti」をタイトルに使い、
背景は和紙のようなテクスチャ。色は墨色（#2d2d2d）ベースに朱色（#c0392b）のアクセント。
レイアウトは左右非対称で、余白を大胆にとる。
```

> ポイント: 「和モダン」「北欧ナチュラル」「レトロフューチャー」「ブルータリスト」など、具体的な形容詞を使うとAIっぽさが消えます。

---

### 応用例

- 結婚式・パーティーの招待ページ
- 個人ポートフォリオ（作品集）サイト
- お店の紹介サイト（カフェ、サロン、教室など）
- サークルや趣味の活動報告ページ
- イベントのランディングページ

### Tips & コツ

- **「ブラウザで開いて」** とお願いするだけで、何度でもプレビュー確認できます。修正→確認を繰り返しましょう
- **画像はあとから差し替え可能**。最初はダミー画像で配置だけ決めてもらうのがおすすめ
- **Tailwind CSS** (Web デザインを楽に整える人気のツールキット) を使うように指示すると、よりクオリティの高いデザインになりやすいです
  ```
  Tailwind CSS の CDN を使ってスタイリングしてください。
  ```
- **Git で保存** しておくと、いつでも前の状態に戻せるので安心です
  ```
  Git で今の状態を「初版」として保存しておいてください。
  ```
- **GitHub Pages** を使えば、作ったサイトを無料でインターネットに公開できます。Claude に「GitHub Pages にデプロイする手順を教えて」と聞いてみてください


## 事例 2: チラシ作り

### 概要

Claude Code を使えば、イベント告知やお店のメニューなどのチラシをプロ品質で作れます。
HTML/CSS でデザインし、ブラウザの印刷機能で PDF に変換するシンプルな流れです。
Canva などのデザインツールを使わなくても、日本語で指示するだけで完成します。

> 👤 **こんな人におすすめ**: 教室・サロン・お店を運営している方、イベント主催者、勉強会や交流会の告知をしたい方

> 🎯 **この事例に向くツール: 「Cowork」タブ**
> 「○○のチラシを作って」と **成果物がはっきりしている** ので、全自動でやり切ってくれる **Cowork** が向いています。
> もちろん「コード」タブでも作れますし、こだわって少しずつ調整したいときは「コード」のほうが便利です。

---

### 必要な準備

- **Claude デスクトップアプリ** がインストール済みでログイン済みであること
- **ブラウザ**（Safari, Chrome など。デザイン確認 & PDF変換用）

---

### 手順

#### Step 1: 作業フォルダを準備する

- デスクトップなどお好きな場所に **新規フォルダ** を作成してください（例: `my-flyer`）
  - 右クリック → 「新規フォルダ」(Mac) / 「新規作成」→「フォルダー」(Windows)

#### Step 2: 「Cowork」タブを開く

- Claude デスクトップアプリを起動し、画面左上の **「Cowork」** ボタンをクリック
- 作業フォルダを聞かれたら Step 1 で作ったフォルダを選択

> 「コード」タブで進める場合も、同じくフォルダを選択するだけです。

#### Step 3: CLAUDE.md を作る（チラシの仕様書）

チラシのサイズや印刷向けの設定をまとめた指示書を作ります。

```
以下の内容で CLAUDE.md ファイルを作成してください。

# チラシ作成ルール
- HTMLファイル1つ（index.html）で完結させる
- サイズ: A4縦（210mm x 297mm）
- @media print で印刷用のページサイズを指定する
- 余白: 上下左右15mm以上（印刷時の裁ち落とし考慮）
- Google Fonts の日本語フォントを使用する
- 画像が必要な箇所は placeholder.co (ダミー画像を自動生成してくれる無料サービス) のダミー画像を使用する
- 背景色は印刷に適した明るいベースにする
```

> A4縦 がもっとも一般的なチラシサイズです。横向きにしたい場合は「A4横（297mm x 210mm）」に変えてください。

#### Step 4: プランモードでチラシの計画を確認する

**プランモード (Plan mode)** は、いきなり実行せずに **「どう作るか」の計画だけを先に提示** してもらうモードです。

「コード」タブで進めている場合は、 **モードセレクタから「プランモード」** を選んで (数字キー **3** でもOK) から、以下を入力します。
（Cowork タブで進めている場合は、そのままプロンプトを入れて Enter で全自動実行されます）

```
ヨガ教室の体験レッスン告知チラシを作ってください。

掲載情報:
- 教室名: Yoga Studio Calm
- キャッチコピー: 「心と体を整える、はじめての一歩」
- 体験レッスン日時: 毎週土曜 10:00〜11:30
- 場所: ○○市文化センター 2F 多目的ホール
- 料金: 初回無料
- 持ち物: 動きやすい服装、タオル、飲み物
- 講師紹介: 山田花子（ヨガ歴15年、全米ヨガアライアンス認定）
- 予約方法: LINE公式アカウント @yoga-calm
- QRコード用のスペース（あとで画像を差し替える）

デザイン:
- ナチュラルで落ち着いた雰囲気
- メインカラー: カーキグリーン系
- フォント: Noto Sans JP
- ヨガのポーズ写真が入るスペースを確保（ダミー画像でOK）
```

> 「コード」タブの場合: 計画を確認して、良ければ **モードセレクタを「許可を確認」(数字キー 1) に戻して** から「この計画で進めてください」と伝えます。
> Cowork タブの場合: そのまま結果を待ちます。

#### Step 5: デザインを確認する

```
作った index.html をブラウザで開いてください。
```

> ブラウザでチラシのデザインが表示されます。
> 「コード」タブのプレビュー機能が使えるときは、その場でも確認できます。

#### Step 6: 修正を依頼する

気になる部分は日本語で伝えるだけで修正できます。

```
タイトルをもっと目立つように大きくして、背景にうっすら葉っぱのイラスト（SVG）を追加してください。
```

```
料金のところを枠で囲んで、もっと目立つようにしてください。
```

#### Step 7: PDF に変換する

デザインが完成したら、PDFファイルにして印刷できるようにします。

**方法1: ブラウザの印刷機能（最も簡単）**

1. ブラウザでチラシを開いた状態で **Cmd + P**（印刷）
2. 送信先を **「PDFとして保存」** に変更
3. 用紙サイズが **A4** になっていることを確認
4. **「余白」を「なし」** に設定
5. 「保存」をクリック

> これだけで印刷可能なPDFファイルが完成します。

**方法2: Claude Code にPDF生成を頼む** ⚙️ (上級者向け)

```
このチラシを puppeteer を使ってPDFファイルとして出力するスクリプトを作って実行してください。
A4サイズ、余白なしで出力してください。
```

> 💡 **Puppeteer ってなに?** ブラウザを自動操作してPDFやスクショを生成するツール。Node.js (JavaScript の実行環境) が必要です。
>
> 方法1のブラウザ印刷で十分な場合はこちらは不要です。 **初心者の方は方法1がおすすめ** 。

---

### AIっぽくないデザインにするには

チラシでも、AIに任せきりだと「テンプレ感」が出がちです。以下の工夫で差をつけましょう。

#### よくあるAIっぽいチラシ（NG例）

- ありきたりなレイアウト（上にタイトル、中央に写真、下に情報）
- 紫〜青のグラデーション
- 均等に並んだ要素で余白が中途半端
- 特徴のない色使い

#### 対策1: `/frontend-design` スキルを使う

```
/frontend-design

ヨガ教室の体験レッスンチラシを作ってください。
ナチュラルで温かみのある雰囲気、手作り感のあるデザインにしたいです。
```

> スキルがまだ入っていない場合は、Claude に「frontend-design スキルを使えるようにして」と頼むと案内してくれます。

#### 対策2: 具体的なデザイン方向性を伝える

NG: 「おしゃれなチラシにして」

OK:
```
ナチュラル系のデザインで、リネン素材のようなテクスチャを背景に使い、
手書き風のアクセントを入れてください。色はカーキとベージュをベースに、
テラコッタカラーをアクセントに。フォントは「M PLUS Rounded 1c」で柔らかい印象に。
レイアウトは上下2分割ではなく、斜めの区切り線で動きを出してください。
```

#### 対策3: CLAUDE.md にNGリストを書く

```markdown
# デザインで避けること
- テンプレートのような定型レイアウトは避ける
- Inter, Roboto, Arial は使わない
- 紫〜青のグラデーションは禁止
- 要素を均等に並べず、強弱をつける
```

### 応用例

- お店のメニュー表（カフェ、レストラン）
- イベント・セミナーの告知ポスター
- 名刺のデザイン
- 案内状・招待状
- 教室の時間割・プログラム表
- セール・キャンペーンのお知らせ

---

### Tips & コツ

- **ブラウザの印刷（Cmd + P → PDF保存）が最も簡単なPDF変換方法**です。まずはこれで試しましょう
- **A4サイズの指定**は `width: 210mm; height: 297mm;` で行います。CLAUDE.md に書いておけばClaude が自動的に適用してくれます
- **日本語フォント** のおすすめ:
  - `Noto Sans JP` — 読みやすいゴシック体
  - `Noto Serif JP` — 上品な明朝体
  - `M PLUS Rounded 1c` — 柔らかい丸ゴシック
  - `Kaisei Opti` — 和風でモダンな印象
  - `Zen Maru Gothic` — 親しみやすい丸ゴシック
- **画像はあとから差し替え可能**。まずダミー画像で配置を決めてから、実際の写真に入れ替えましょう
- **QRコードの画像**は、QRコード生成サイトで作成して差し替えるのがおすすめです
- **`pdf` スキル** を使えるようにすると、PDF操作がさらに便利になります。Claude に「pdf スキルを使えるようにして」と頼んでみてください。


## 事例 3: 動画編集

### 概要

Claude Code を使えば、動画のカット、結合、字幕追加、フォーマット変換などを日本語で指示するだけで実行できます。
裏側では **FFmpeg** (動画を加工するためのオープンソースの定番ツール) が動いていますが、難しいコマンドを覚える必要はありません。
「この動画の30秒から1分30秒だけ切り出して」と伝えるだけでOKです。

> 👤 **こんな人におすすめ**: YouTube / TikTok / Instagram リール用に動画を編集したい方、セミナー動画から要点だけ切り出したい方、動画から GIF を作って SNS で使いたい方

> 🎯 **この事例に向くツール: 「Cowork」タブ**
> 無音カット・字幕追加など **定型処理で時間がかかる** ので、全自動で最後までやり切ってくれる **Cowork** が向いています。
> 細かく結果を見ながら調整したいときは「コード」タブも便利です。

---

### 必要な準備

- **Claude デスクトップアプリ** がインストール済みでログイン済みであること
- **FFmpeg**（動画を処理するためのツール。Claude に頼めばインストール案内をしてくれます）
- **編集したい動画ファイル**

#### FFmpeg がまだ入っていないとき

> 💡 **Homebrew ってなに?**
> Mac に便利なツールを一発でインストールできる、エンジニア定番のパッケージマネージャー。 FFmpeg もこれを使って入れます。

Claude にお願いするのが一番ラクです。

```
FFmpegを使いたいので、Macにインストールする手順を案内してください。
インストールが終わったらバージョン確認まで一緒にやってください。
```

> 必要に応じて Homebrew のインストールから案内してくれます。
> 「許可しますか？」画面が出たら、内容を確認のうえ「Yes」を押してください。

---

### 手順

#### Step 1: 動画ファイルを作業フォルダに置く

- デスクトップなどに **新規フォルダ** を作成してください（例: `my-video`）
- 編集したい動画ファイルを、Finder でこのフォルダにコピー（ドラッグ&ドロップ）してください

> ファイル名に日本語やスペースが含まれていると問題が起きることがあります。`input.mp4` のようにシンプルな英数字の名前に変えておくと安心です。

#### Step 2: 「Cowork」または「コード」タブを開く

- Claude デスクトップアプリを起動
- 全自動で進めたいなら **「Cowork」** タブ、対話しながら進めたいなら **「コード」** タブをクリック
- 作業フォルダを聞かれたら Step 1 のフォルダを選択

#### Step 3: まず動画の情報を確認する

何ができるか知るために、まず動画の中身を確認してもらいましょう。

```
input.mp4 の動画情報（解像度、長さ、ファイルサイズなど）を教えてください。
```

> 動画の長さ、画質、ファイルサイズなどが表示されます。この情報をもとに、次の編集を進めます。

#### Step 4: やりたい編集を日本語で伝える

以下のプロンプト例をコピペして、必要に応じて内容を変えてください。

**動画のトリミング（一部を切り出す）**

```
input.mp4 の 0:30 から 1:30 までを切り出して、output.mp4 として保存してください。
```

**字幕を追加する**

```
input.mp4 に以下の字幕を追加して、subtitled.mp4 として保存してください。

0:00-0:05 「こんにちは！今日は手作りアクセサリーの作り方を紹介します」
0:05-0:10 「用意するものはこちら」
0:10-0:20 「まずビーズを糸に通していきます」
```

**動画をGIFに変換する**

```
input.mp4 の 0:05 から 0:10 の部分をGIFアニメーションに変換してください。
横幅480pxで、ファイルサイズが小さくなるように最適化してください。
```

**サムネイル画像を作る**

```
input.mp4 の 0:15 のフレームをサムネイル画像（thumbnail.jpg）として保存してください。
```

**複数の動画を結合する**

```
video1.mp4 と video2.mp4 と video3.mp4 をこの順番で結合して、combined.mp4 として保存してください。
```

**動画を圧縮する（ファイルサイズを小さく）**

```
input.mp4 を画質をなるべく維持したまま、ファイルサイズが半分程度になるように圧縮して、
compressed.mp4 として保存してください。
```

**動画のフォーマットを変換する**

```
input.mov を MP4 形式に変換してください。
```

#### Step 5: 結果を確認する

```
output.mp4 をデフォルトの動画プレイヤーで開いてください。
```

> Finder で出力ファイルをダブルクリックしてもOKです。

#### Step 6: さらに編集を重ねる

満足できるまで、追加の編集を何度でも依頼できます。

```
output.mp4 の再生速度を1.5倍にしてください。
```

```
output.mp4 にBGMとして music.mp3 を追加してください。
BGMの音量は動画の音声の30%くらいにしてください。
```

### 応用例

- **SNS用の短尺動画**: 長い動画から見どころだけを切り出してリール/ショート動画に
- **動画からGIF作成**: ブログやSNSに貼れるGIFアニメーションを作成
- **BGM追加**: 無音の動画にバックグラウンドミュージックを追加
- **動画の圧縮・リサイズ**: メール添付やSNSアップロード用にファイルサイズを縮小
- **バッチ処理**: フォルダ内の複数動画を一括で変換・リサイズ

### 発展: Remotion で動画をゼロから作る ⚙️ (上級者向け)

> ⚠️ ここから先は **プログラミング経験者向け** の発展トピックです。まずは前章の FFmpeg 編集だけで十分なので、初心者の方はスキップして OK です。

さらに進んだ使い方として、**Remotion** というツールを使えば、コードで動画をゼロから生成できます。

Remotion は React（Webアプリ開発のフレームワーク）を使って動画を作るツールです。
テキストアニメーション、画像のスライドショー、データの可視化など、プログラムで制御した動画が作れます。

```
Remotion を使って、自己紹介動画を作ってください。

内容:
- 名前: 山田花子
- 職業: ヨガインストラクター
- 趣味: 読書、旅行
- 背景: 柔らかいグラデーション
- テキストがフェードインするアニメーション
- 長さ: 15秒
```

> Remotion のスキルを使えるようにすると、より高品質な動画が作れます。Claude に「remotion-best-practices スキルを使えるようにして」と頼んでみてください。

> 注意: Remotion は Node.js の知識が多少必要です。まずは FFmpeg での編集から始めるのがおすすめです。

---

### Tips & コツ

- **FFmpegのコマンドを覚える必要はありません**。やりたいことを日本語で伝えれば、Claude Code が適切なコマンドを生成して実行してくれます
- **元の動画ファイルは上書きされません**。出力ファイル名を別にするので安心です。念のため元ファイルのバックアップを取っておくとより安心
- **まず短い動画でテスト**しましょう。大きなファイル（数GB）は処理に時間がかかります
- **「この動画の情報を教えて」** と聞くと、解像度・コーデック・長さなどを教えてくれます。トラブル時の原因特定にも便利です
- **複数の操作をまとめて依頼**できます:
  ```
  input.mp4 を以下の手順で編集してください:
  1. 0:10 から 2:00 を切り出す
  2. 字幕を追加（「チャンネル登録お願いします」を最後の5秒間表示）
  3. MP4で出力
  ```
- **動画のファイル名**は英数字のシンプルなものにしておくと、トラブルが少ないです


## 事例 4: SNS 投稿コンテンツの自動生成

### 概要

「投稿ネタが思いつかない…」「毎日の投稿文を書くのが大変…」そんな悩みを Claude Code が解決します。
楽天ROOM、Instagram、X（旧Twitter）など、どんな SNS でも使える投稿ネタ・文章を一気に生成できます。

> 👤 **こんな人におすすめ**: 楽天ROOM ユーザー、Instagram で商品紹介・ハンドメイドアカウントを運営している方、毎日の投稿が負担になっている方、月間コンテンツカレンダーを整えたい方

> 🎯 **この事例に向くツール: 「コード」と「Cowork」を使い分け**
> - **Cowork** が向くケース: 「1週間分の投稿ネタを一括生成」「Instagram用キャプション10件を一気に作る」など **まとめて作る** 系
> - **「コード」** が向くケース: 「もう少し優しい口調に」「ハッシュタグを5個に減らして」など **トーンを少しずつ調整** する系
> - 迷ったら、まず Cowork で一括生成 → コードで微調整、の流れがおすすめ

---

### 必要な準備

- **Claude デスクトップアプリ** がインストール済みでログイン済みであること
- 投稿したい **SNS のジャンルやテーマ** を決めておく（例：美容グッズ、ハンドメイド、カフェ巡り など）

---

### 手順

#### Step 1: 作業フォルダを作る

- デスクトップなどに **新規フォルダ** を作成してください（例: `sns-content`）

#### Step 2: タブを開いてフォルダを指定

- Claude デスクトップアプリを起動
- 一気に生成するなら **「Cowork」** タブ、対話しながら進めるなら **「コード」** タブをクリック
- 作業フォルダを聞かれたら Step 1 のフォルダを選択

#### Step 3: 1週間分の投稿ネタを一気に作る

以下のプロンプトをコピペして、自分の情報に書き換えてから入力してください。

```
私は楽天ROOMで美容グッズを紹介しています。

1週間分（月〜日）の投稿ネタを考えてください。
それぞれの投稿について、以下を作成してください:

- 投稿のテーマ（何について書くか）
- キャッチコピー（思わず読みたくなる一言）
- 投稿文（200文字程度、親しみやすい口調で）
- おすすめハッシュタグ（5個）

結果は見やすい表形式で、sns-plan.md というファイルに保存してください。
```

> Claude Code が 1週間分の投稿プランを自動で作ってくれます！

#### Step 4: 朝コレ・0コレ用のテンプレートを作る

楽天ROOM ユーザー向けに、毎日の定型投稿を効率化するテンプレートも作れます。

```
楽天ROOMの「朝コレ」「0コレ」用の投稿テンプレートを作ってください。

- 朝コレ: 毎朝の挨拶 + 今日のおすすめ商品を紹介する投稿
- 0コレ: 深夜0時に投稿する、お得情報やタイムセール商品の紹介

それぞれ5パターンずつ、コピペですぐ使えるようにしてください。
口調は「〜だよ！」「〜してみてね♪」のような親しみやすい感じで。

templates.md に保存してください。
```

#### Step 5: Instagram 用のキャプションを作る

Instagram 向けの投稿文も同じように作れます。

```
Instagramでハンドメイドアクセサリーを紹介するアカウントを運営しています。

以下の3つの商品について、それぞれ Instagram 用のキャプションを書いてください:

1. 天然石のピアス（ラピスラズリ）
2. ビーズの編み込みブレスレット
3. レジンの花モチーフネックレス

各キャプションに含めるもの:
- 目を引く1行目（改行なしで表示される部分）
- 商品の魅力を伝える本文（3〜5行）
- おすすめハッシュタグ（10個以上、日本語・英語混合）
- 投稿に最適な時間帯のアドバイス

instagram-captions.md に保存してください。
```

#### Step 6: 投稿カレンダーを HTML で作る

作ったネタを見やすいカレンダー形式にまとめることもできます。

```
sns-plan.md の内容をもとに、1週間分の投稿カレンダーをHTMLで作ってください。

- 曜日ごとに投稿内容がカードで表示される
- 各カードに「テーマ」「投稿文」「ハッシュタグ」を表示
- 投稿文はクリックでコピーできるボタン付き
- スマホでも見やすいデザイン
```

```
作った calendar.html をブラウザで開いてください。
```

> ブラウザで投稿カレンダーが表示されます。投稿文をコピーして、そのまま SNS に貼り付けられます！
> 「コード」タブのプレビュー機能でその場で確認することもできます。

---

### 応用例

- **月間コンテンツカレンダー** を作って、投稿計画を立てる
- **商品レビューの下書き** を一括生成して、あとから微調整する
- **季節イベント（セール、母の日、クリスマスなど）** に合わせた特別投稿を準備する
- **フォロワーに聞くアンケート投稿** のネタを考えてもらう
- **プロフィール文** を魅力的に書き直してもらう

---

### Tips & コツ

- **自分の口調を教えてあげる** と、より自分らしい文章になります
  ```
  私の口調の特徴: 「〜だよ！」「〜なの♡」をよく使います。絵文字は🌸💕✨が好きです。
  この口調で投稿文を書いてください。
  ```
- **過去のバズった投稿** を参考に見せると、同じテイストで新しいネタを提案してくれます
  ```
  過去にバズった投稿はこれです:「（投稿文をコピペ）」
  同じようなテイストで、新しい投稿を5つ考えてください。
  ```
- **NG ワードを指定** しておくと安心です
  ```
  以下のワードは使わないでください: （薬機法に抵触しそうな表現など）
  ```
- 生成された文章は **必ず自分で確認してから投稿** しましょう。AIが作った文章をそのまま使うと、事実と異なる内容が含まれている可能性があります
